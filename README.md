# هم‌قدم

یک نمونه‌ی اولیه‌ی فارسی و راست‌چین برای برنامه‌ریزی و پیگیری مطالعه‌ی کنکور. رابط کاربری واکنش‌گراست و به‌صورت PWA امکان نصب و باز شدن آفلاین دارد. فهرست کارهای روزانه در حافظه‌ی مرورگر ذخیره می‌شود.

## اجرا

به Python 3.9 یا جدیدتر نیاز دارید؛ کتابخانه‌ی اضافی لازم نیست.

```powershell
python app.py
```

سپس در مرورگر به [http://127.0.0.1:8000](http://127.0.0.1:8000) بروید. برای توقف سرور `Ctrl+C` را بزنید.

برای نصب PWA یا استفاده‌ی آفلاین، برنامه را در مرورگری باز کنید که Service Worker را پشتیبانی می‌کند. در اجرای محلی، `localhost` معتبر است؛ برای دسترسی از دستگاه‌های دیگر، مقدار `HAMGHADAM_HOST` را به `0.0.0.0` تغییر دهید و برنامه را فقط روی شبکه‌ی مورداعتماد اجرا کنید.
